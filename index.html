Las tarifas oficiales del INS para esta combinación específica presentan inconsistencias (la columna duplica valores de Grandes Deducibles $5,000 para algunas edades). Mientras INS publica el archivo corregido, esta combinación está deshabilitada. Ampliar cobertura de epidemias y pandemias
Sin ampliar: $7.500 (Regional) / $15.000 (Internacional y GD). Con ampliación: $75.000 / $200.000. La prima sube ~17%.
⚠
Hay asegurados de 70 años o más. El INS permite escoger entre Con Reducción de Suma Asegurada (la suma asegurada baja a partir de los 70) o Sin Reducción (la suma asegurada se mantiene, con prima mayor).
